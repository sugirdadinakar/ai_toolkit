# AI PM Kit Marketplace

Claude Code marketplace for the [AI PM Kit](https://github.com/sugirdadinakar/ai_toolkit) plugin.

## Install

```bash
claude plugin marketplace add sugirdadinakar/ai_toolkit
claude plugin install ai_toolkit
```

## What's included

- **ai_toolkit** — 15 PM commands, 19 skills, and 5 specialist agents for product management

## About this directory

**This directory is a scaffold, not part of the plugin itself.** It exists in the plugin repo purely as a convenience — its contents should be published as a separate GitHub repo at `ai_toolkitmarketplace`. Claude Code reads the marketplace repo to discover available plugins.

See [PUBLISHING.md](../PUBLISHING.md) in the plugin repo for the full step-by-step publishing guide.
